Features

Everything you need,
nothing you don't

A focused set of capabilities designed to make you more productive. No bloat, no complexity—just powerful tools that work.

Intelligent Code Generation

Write complete functions, files, or entire projects from natural language. Understands context, conventions, and best practices.

Persistent Memory

Remembers your preferences, project patterns, and past decisions. Learns from every session to become more helpful over time.

How It Works

From idea to implementation
in seconds

Three simple steps to supercharge your terminal workflow.

01

Install in seconds

One command to install. One command to run. No complex setup, no configuration files to maintain. Just pip install and you're ready.

# Install with pipx (recommended)
pipx install ite-agent

# Or with pip
pip install ite-agent
02

Configure your API key

Run ite for the first time and follow the prompts to enter your API credentials. Stored securely in your local config.

# First run - guided setup
$ ite

Welcome to ITE!
Enter your API key:
03

Start building

Type natural language commands and watch the magic happen. Plan mode for complex tasks, instant execution for simple ones.

$ ite
