# Download and Install Epic Games Launcher and Unreal Engine

## Steps

1. Go to [unrealengine.com](https://www.unrealengine.com/) and click "Download"
2. Run the Epic Games Launcher installer
3. Launch the Epic Games Launcher
4. Click on "Unreal Engine" in the left sidebar
5. Click "Install Engine" and choose a version (recommended: latest stable)
6. Select installation location and complete the installation

## Notes

- The engine requires ~30-50GB of disk space
- Choose the installation path carefully as it will be large
