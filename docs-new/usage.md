# Usage

Start iTE from any project directory:

```bash
cd my-project
ite
```

You'll see a chat interface. Just start typing.

## Ask

Ask about code, architecture, or how things work:

```
How does the authentication system work?
```

iTE searches and explains.

## Plan Mode

For larger changes, use plan mode. iTE asks questions and produces a plan before implementing:

```
/plan on
```

Discuss the approach. When ready to execute:

```
/plan off
```

## Undo/Redo

If something goes wrong:

```
/undo
```

Reverts file changes from the last turn.

```
/redo
```

Reapplies reverted changes.

## Sessions

Conversations auto-save. List or resume previous sessions:

```
/sessions
```

Type `/help` for a full list of commands.
